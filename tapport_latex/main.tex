\begin{abstract}
Ce rapport présente la conception et l'implémentation du \textit{Student Gotham Bat Database}
(SGBD), un système de gestion de base de données relationnel développé en Java dans le cadre
du projet intégratif de l'ITI. Le système supporte un sous-ensemble du langage SQL incluant
la création de tables, l'insertion, la sélection avec jointures, la suppression et la
persistance des données.
\end{abstract}
